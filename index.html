Инструкция по выгрузке отчётов

Пошаговое руководство для ВАТС и Инфопанели ТТК (FORapp)

1 Выгрузка звонков (Для ИТМ) — ВАТС

Открыть ВАТС
  1. Перейдите на сайт ВАТС ТТК: 20vatc006325-001.cloudpbx.ttk.ru
  2. Перейдите во вкладку «История» (раздел «Внешние звонки»).
  3. Укажите нужный Период (например, «Вчера», «Сегодня» или интервал дат).
  4. В поле поиска в правом верхнем углу введите фамилию агента.
  5. Нажмите на иконку «XLS» в правом верхнем углу для выгрузки отчёта.

2 Выгрузка раскидки / расклейки (FORapp)

Открыть Uber ТТК
  1. Перейдите в дашборд: uber.ttk.ru/dashboard
  2. Откройте вкладку «Отчеты» в левом боковом меню.
  3. В блоке фильтров настройте два параметра:
    • Узел → По названию → укажите ваш узел;
    • Отчет → По дате и времени создания → задайте интервал с 00:00 по 23:59.
  4. Нажмите синюю кнопку «Применить».
  1. Скачайте чистый шаблон выгрузки, нажав:
  2. В верхнем меню нажмите кнопку «Экспорт» (выберите формат XLSX).
  3. В блоке «Загрузите схему экспорта» нажмите «Прикрепить excel файл» и выберите скачанный шаблон.
  4. Нажмите синюю кнопку «Экспорт» для получения файла.
